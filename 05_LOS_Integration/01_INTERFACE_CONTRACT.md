# LOS interface contract

Base path `/api/v1`. OpenAPI is generated by the running FastAPI service at `/openapi.json` (download and pin it during integration). Swagger is at `/docs` on the backend; protected API operations still require a bearer token. This package includes a schema-export script under Tests.

## Authentication and ownership
Entra JWT, RS256, tenant/issuer/audience validation and application role `LOS` for inbound creation/upload. The LOS service principal needs explicit case membership for retrieval; only Admin assigns additional members. `LOS` cannot review fields, issue clearances or make decisions. For user actions the API requires the corresponding user role, not an LOS service token.

LOS owns the application lifecycle and booking; VCA owns its evidence, assessment and review history. In this prototype the final human decision is recorded in VCA and published to LOS. If your LOS owns approval, replace this adapter contract with a validated decision-import route; do not create competing decisions.

## Endpoints
| Method | Endpoint | Meaning |
|---|---|---|
| POST | `/applications` | Create; requires `Idempotency-Key`. Same key/content returns same case; changed content returns 409. |
| POST | `/applications/{id}/documents` | Multipart `file`; returns 202 with document/job IDs; SHA-256 deduplication per case. |
| GET | `/applications/{id}/status` | Current case version, stage, revision and assessment reference. |
| GET | `/applications/{id}/assessment` | Immutable latest assessment snapshot, or 409 if stale/unavailable. |
| GET | `/applications/{id}/reports?kind=credit_report&format=docx` | Authorised report download. |
| POST | `/applications/{id}/assessments` | Human Analyst/Admin only; confirms reporting period/base currency. |

The last endpoint deliberately cannot be invoked by the LOS role to bypass field review.

## Events
`application.created`, `document.processed`, `assessment.completed`, `application.status_changed`, `decision.recorded`.
Envelope: `id`, `created_at`, `type`, `application_id`, `payload`. Payloads contain references/statuses rather than full borrower documents. Delivery is at least once. Consumers deduplicate by event ID. Three attempts with backoff; terminal failures remain visible in jobs and the event's pending delivery status. An authorised operator can inspect and requeue failed outbox jobs after repairing connectivity; see runbook.

Signature: HMAC-SHA256 over `timestamp + '.' + raw_body`; headers `X-VCA-Timestamp`, `X-VCA-Signature`, `X-VCA-Event-ID`. Receiver rejects timestamps outside 5 minutes and changed payloads with an existing event ID. Credentials stay in environment/Key Vault. Callback destination is administrator configuration; never accept an arbitrary callback URL in a case request.

## Concurrency and errors
Mutation requests carry `expected_version` for reviewed records/cases. HTTP 409 means refresh and reassess, not force overwrite. Other statuses: 400 validation, 401 identity, 403 role/authority, 404 absent or unauthorised case, 413 file limit, 503 dependency unavailable. Correlation ID is returned in `X-Request-ID`; no financial data in application logs.

## Still needed for a live LOS
Vendor/version, actual API specification, field mapping, document-transfer method, service principals, network route, callback endpoint and system-of-record agreement. The simulator proves the interface without claiming a live bank connection.
