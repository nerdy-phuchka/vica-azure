Run commands from the extracted application root so the numbered folders keep
their relative paths. Configure the Azure subscription, region/model, Entra
registrations and roles, and the bank's approved credit policy as documented.
UI policy drafts do not activate the server-side lending policy.

The standalone HTML preview uses demonstration data. The connected frontend
runs through the Next.js application and requires the authenticated backend.
